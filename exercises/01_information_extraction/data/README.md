# Example PDFs

## `pdfs/nhess-15-365-2015.pdf`

Bruwier, M., Erpicum, S., Pirotton, M., Archambeau, P., and Dewals, B. J.:
Assessing the operation rules of a reservoir system based on a detailed modelling chain,
Nat. Hazards Earth Syst. Sci., 15, 365–379, https://doi.org/10.5194/nhess-15-365-2015, 2015.

License: Copernicus **CC BY 3.0**. Redistributable with citation.

The paper describes two multi-purpose reservoirs on the Vesdre (Meuse basin, Belgium):
**Eupen dam** and **La Gileppe dam**. The following table provides approximate values you can check against an
extraction (do not treat these as exact ground truth):

| Field | Eupen / La Gileppe (order of magnitude) |
|---|---|
| Country | Belgium |
| River | Vesdre |
| River basin | Meuse |
| Dam height | ~50 m |
| Total storage | ~25×10⁶ m³ |
| Flood / free storage | ~3×10⁶ m³ |
| Control type | controlled (operating rules) |
